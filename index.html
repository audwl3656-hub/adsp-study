척도특징가능연산예시
명목분류만 가능, 순서 없음빈도, 최빈값성별, 혈액형
순서순위 있음, 간격 불일정중앙값, 순위학점(A/B/C)

귀무가설 채택귀무가설 기각
실제 참✅ 정상❌ 1종 오류(α)
실제 거짓❌ 2종 오류(β)✅ 정상
1종 오류가 더 심각 — p-value < 0.05 → 귀무가설 기각
검정 종류 선택
  • t검정 — 연속형, 2그룹 평균 비교
  • F검정(ANOVA) — 연속형, 3그룹 이상
  • 카이제곱(χ²) — 범주형, 독립성/연관성
  • Z검정 — 모분산 알 때
03-A+

EDA · 기술통계 심화

EDA의 핵심 관점
EDA 4가지 강조점
  • 저항성 — 이상값에 덜 흔들리는 통계량 사용. 중앙값, 사분위수, IQR이 대표적
  • 잔차 계산 — 관측값과 모형 예측값의 차이를 확인해 패턴·이상값을 파악
  • 자료 변수의 재표현 — 로그, 제곱근, 표준화 등으로 분포·관계를 보기 좋게 변환
  • 그래프를 통한 현시성 — 히스토그램, 상자그림, 산점도 등으로 구조를 시각적으로 확인
R 요약·빈도 확인
summary(df) // 수치형 요약 + NA's 확인
table(df$survived) // 범주형 빈도 확인
prop.table(table(df$survived)) // 범주형 비율
summary 함수의 NA's는 결측치 개수다. 범주형 변수 빈도는 table()로 확인한다.
이상값 판정 기준
ESD / 3-Sigma 기준
|x - 평균| > 3 × 표준편차

평균으로부터 표준편차의 약 3배 이상 떨어진 값은 이상값 후보로 본다. 정규분포에 가까운 데이터에서 자주 사용한다.

IQR 기준
IQR = Q3 - Q1
이상값: x < Q1 - 1.5×IQR 또는 x > Q3 + 1.5×IQR

IQR은 중간 50%의 산포를 나타내므로 평균은 알 수 없다. 대신 이상값에 강한 저항성 통계량이다.

공분산·상관계수
공분산 핵심
Cov(X,Y)=E[(X-μx)(Y-μy)]
  • 두 변수가 함께 변하는 방향을 나타낸다.
  • X, Y가 독립이면 공분산은 0이다.
  • 공분산이 0이라고 반드시 독립은 아니다.
  • 공분산과 피어슨 상관계수는 주로 선형관계를 본다.
왜도와 첨도
개념해석
왜도분포의 비대칭 정도. 양의 왜도는 오른쪽 꼬리, 음의 왜도는 왼쪽 꼬리가 길다.
첨도분포의 뾰족함과 꼬리 두꺼움. 첨도가 높으면 중심이 뾰족하고 극단값 가능성이 커진다.
양의 왜도: 평균 > 중앙값 > 최빈값 / 음의 왜도: 평균 < 중앙값 < 최빈값

확률분포 · 표본추출 · 추정

표본추출 방법
방법핵심예시
단순랜덤추출모든 표본이 동일 확률로 선택난수표로 100명 추출
계통추출첫 표본을 무작위 선택 후 일정 간격 k마다 추출명단에서 10명마다 1명
집락/군집추출모집단을 여러 집락으로 나누고 일부 집락을 통째로 추출몇 개 학교를 뽑아 전수조사
층화추출모집단을 동질적인 층으로 나눈 뒤 각 층에서 추출성별·연령대별 비례 추출
🔥 집락추출 vs 층화추출 차이
  • 집락추출: 집락 안은 모집단과 비슷하게 다양하고, 뽑힌 집락을 통째로 조사한다.
  • 층화추출: 층 안은 서로 비슷하게 동질적이고, 모든 층에서 일부씩 뽑아 대표성을 높인다.
확률분포
이산확률분포
  • 베르누이 — 성공/실패 1회
  • 이항분포 — 베르누이 시행 n회 중 성공 횟수
  • 기하분포 — 첫 성공까지 필요한 시행 횟수
  • 다항분포 — 범주가 3개 이상인 시행 횟수
  • 포아송분포 — 단위 시간·공간에서 사건 발생 횟수
연속확률분포
  • 균일분포 — 구간 내 확률이 동일
  • 정규분포 — 평균 중심 좌우대칭, 평균=중앙값=최빈값
  • t분포 — 모분산 미지, 표본이 작을 때 평균 검정·추정
  • 카이제곱분포 — 분산 검정, 적합도·독립성 검정
  • F분포 — 두 분산비, ANOVA와 회귀모형 전체 검정
중심극한정리와 표본분포
중심극한정리

모집단 분포가 정규분포가 아니어도 표본크기 n이 충분히 크면 표본평균의 분포는 정규분포에 가까워진다.

E(X̄)=μ
Var(X̄)=σ²/n
SE(X̄)=σ/√n
평균·분산·표준편차
평균 = Σx / n
분산 = Σ(x-평균)² / n 또는 n-1
표준편차 = √분산
표준오차 = 표준편차 / √n
점추정과 구간추정
성질의미
불편성추정량의 기대값이 실제 모수와 같음
효율성분산이 작아 더 안정적인 추정량
일치성표본크기가 커질수록 추정량이 모수에 가까워짐
충족성추정량이 모수에 대한 정보를 충분히 담고 있음
모분산 σ²을 아는 경우
X̄ ± zα/2 × σ/√n

모표준편차 σ를 알면 Z분포를 사용한다.

모분산 σ²을 모르는 경우
X̄ ± tα/2,n-1 × s/√n

모표준편차를 모르고 표본표준편차 s를 사용하면 t분포를 사용한다.

귀무가설 H0
  • 귀무가설은 보통 차이가 없다, 효과가 없다, 관계가 없다는 기본 가정이다.
  • p-value < α이면 귀무가설을 기각하고 대립가설을 채택할 근거가 있다고 본다.
  • p-value ≥ α이면 귀무가설을 기각하지 못한다. 이때 귀무가설이 참이라고 증명한 것은 아니다.

단순선형회귀
Y = β₀ + β₁X + ε
R²: 설명력 (0~1, 높을수록↑)
t검정: 개별 계수 유의성
F검정: 모형 전체 유의성
로지스틱 회귀
  • 종속변수가 범주형(0/1)일 때
  • 결과를 확률(0~1)로 예측
  • VIF > 10이면 다중공선성 의심
  • 해결: Ridge(L2), Lasso(L1)
03-B+

회귀분석 심화

회귀분석 기본
회귀분석이란?
  • 독립변수 X로 종속변수 Y의 값을 설명·예측하는 분석 방법
  • 잔차 = 실제값 y - 예측값 ŷ
  • 회귀계수 추정은 보통 최소제곱법(OLS): 잔차제곱합 SSE를 최소화
R-square와 변동
SST = SSR + SSE
R² = SSR/SST = 1 - SSE/SST
  • SST: 전체 변동
  • SSR: 회귀모형이 설명한 변동
  • SSE: 모형이 설명하지 못한 잔차 변동
  • R²는 1에 가까울수록 설명력이 좋다.
회귀분석 종류와 규제 회귀
종류핵심
단순선형회귀독립변수 1개로 연속형 종속변수 예측
다중선형회귀독립변수 여러 개로 연속형 종속변수 예측
다항회귀X², X³ 등 비선형 패턴을 선형회귀 형태로 표현
로지스틱 회귀종속변수가 범주형, 특히 이진분류일 때 사용
RidgeL2 패널티. 계수를 작게 줄여 다중공선성 완화
LassoL1 패널티. 일부 계수를 0으로 만들어 변수 선택 효과
Elastic NetL1+L2 결합. Ridge와 Lasso의 장점 절충
교호항: X1×X2처럼 두 독립변수가 함께 작용하는 효과. 예: 광고비 효과가 지역에 따라 달라지는 경우.
선형회귀분석의 기본 가정
가정 4가지
  • 선형성 — X와 Y의 관계가 선형
  • 독립성 — 잔차들이 서로 독립
  • 등분산성 — 잔차의 분산이 일정
  • 정규성 — 잔차가 정규분포를 따름
다중공선성
  • 독립변수들 사이에 강한 선형관계가 있어 회귀계수 추정이 불안정해지는 문제
  • VIF = 1 / (1 - Rj²)
  • 보통 VIF ≥ 10이면 다중공선성을 의심한다.
  • 해결: 변수 제거, 변수 통합, PCA 차원축소, Ridge/Lasso/Elastic Net
상관분석과 모형 선택
피어슨 vs 스피어만
  • 피어슨 상관분석 — 연속형 변수의 선형관계 측정
  • 스피어만 상관분석 — 순위 기반, 단조관계 확인. 이상값·비정규성에 비교적 강함
  • 다중공선성 여부를 볼 때 독립변수 간 상관관계를 함께 확인한다.
AIC / BIC
  • 모형 적합도와 복잡도 패널티를 함께 고려하는 모형 선택 기준
  • AIC, BIC는 작을수록 좋은 모형으로 본다.
  • BIC는 AIC보다 복잡도 패널티가 더 큰 편이다.
회귀 ANOVA와 검정
구분의미검정
회귀변동 SSR모형이 설명한 변동MSR = SSR / 회귀 자유도
잔차변동 SSE모형이 설명하지 못한 변동MSE = SSE / 잔차 자유도
F검정회귀모형 전체 유의성F = MSR/MSE
수정된 R²독립변수 수 증가로 R²가 무조건 커지는 문제 보정변수 수를 고려한 설명력
🔥 회귀모형 검정 암기
  • 모형 전체 유의성: F통계량과 p-value. H0: 모든 회귀계수 β₁=β₂=...=βk=0
  • p-value < α이면 H0 기각 → 적어도 하나의 회귀계수는 유의. 보통 α=0.05
  • 개별 회귀계수 유의성: t통계량과 p-value. H0: 해당 회귀계수 βj=0
  • p-value < α이면 해당 독립변수의 회귀계수가 유의하다고 판단한다.

데이터마이닝 · 지도/비지도 · 분류모형

데이터 마이닝 정의와 절차
데이터 마이닝이란?

대량의 데이터에서 의미 있는 패턴, 규칙, 관계, 지식을 찾아 의사결정에 활용하는 과정이다.

  • 예측: 이탈 고객, 사기 거래, 수요 예측
  • 분류: 스팸/정상, 합격/불합격
  • 군집: 고객 세분화
  • 연관: 장바구니 규칙
일반 절차
① 목적 정의 무엇을 예측·발견할지 결정
② 데이터 수집 내부·외부 데이터 확보
③ 전처리 결측·이상값·스케일 처리
④ 탐색·변환 EDA, 변수 재표현
⑤ 모델링 분류·회귀·군집·연관분석
⑥ 평가·활용 성능 평가 후 업무 적용
지도학습 vs 비지도학습
구분핵심대표 예시
지도학습정답 레이블 Y가 있는 데이터로 학습선형회귀, 로지스틱 회귀, KNN, 나이브 베이즈, 의사결정나무, SVM, 랜덤포레스트
비지도학습정답 레이블 없이 데이터 구조를 발견K-means, 계층적 군집, DBSCAN, PCA, 연관분석
과대적합·과소적합과 검증 방법
과대/과소적합
  • 과대적합 — 훈련 데이터에는 잘 맞지만 검증 데이터 성능이 낮음. 모델이 너무 복잡함
  • 과소적합 — 훈련·검증 데이터 모두 성능이 낮음. 모델이 너무 단순함
  • 교차검증으로 일반화 성능을 확인하고 모델 복잡도를 조절한다.
검증 방법 특징
방법특징
홀드아웃훈련/검증 또는 훈련/테스트를 한 번 나눔. 빠르지만 분할 운 영향
K-foldK개로 나누어 K번 검증. 안정적이고 자주 사용
LOOCV데이터 1개만 검증, 나머지 학습. 데이터가 작을 때 가능하나 계산량 큼
부트스트래핑복원추출로 여러 표본 생성. 표본 통계량·성능 변동 추정에 사용
로지스틱 회귀분석
핵심 개념
  • 종속변수가 범주형, 특히 0/1 이진분류일 때 사용
  • 선형식 결과를 시그모이드 함수로 0~1 확률로 변환
  • 오즈 = p/(1-p): 사건 발생 가능성과 미발생 가능성의 비
  • 로짓 변환 = log(p/(1-p)): 오즈에 로그를 취해 선형식과 연결
추정과 검정
p = 1 / (1 + e-z)
logit(p) = ln(p/(1-p)) = β₀ + β₁X₁ + ... + βkXk
  • 회귀계수는 보통 최대우도법(MLE)으로 추정한다.
  • 가능도는 관측된 데이터가 현재 모형에서 나타날 가능성이다.
  • 가능도가 높을수록 데이터를 더 잘 설명하는 모형으로 본다.
KNN과 나이브 베이즈
KNN
  • 새 데이터와 기존 데이터 사이의 거리를 계산해 가까운 K개 이웃의 범주로 분류
  • 학습 단계에서 별도 모형을 거의 만들지 않는 Lazy Model
  • K값에 따라 결과가 달라진다. K가 너무 작으면 과대적합, 너무 크면 과소적합 가능
  • 거리 기반이므로 스케일링이 중요하다.
나이브 베이즈
  • 베이즈 정리를 이용한 확률 기반 분류기
  • 각 독립변수가 서로 독립이라고 단순하게 가정한다.
  • 계산이 빠르고 텍스트 분류, 스팸 필터링에 자주 사용된다.
  • 독립성 가정이 완벽하지 않아도 실무에서 잘 작동하는 경우가 많다.

  • 평균연결법 — 모든 점쌍 거리의 평균
  • 중심연결법 — 군집 중심 간 거리
Ward 방법
  • 편차제곱합 증가량이 최소가 되도록 군집을 병합
  • 군집 내부 응집도를 높이는 방향
  • 계층적 군집분석에서 자주 출제
K-means와 DBSCAN
K-means
  • K를 사전에 지정해야 한다.
  • K 선택은 Elbow Method를 활용한다.
  • 중심점이 바뀌면 군집이 바뀔 수 있다.
  • 초기 중심점 설정과 이상값에 민감하다.
DBSCAN
  • 밀도 기반 군집 알고리즘
  • K를 사전에 지정하지 않는다.
  • 노이즈와 이상값 탐지에 강하다.
  • 반경 거리 ε와 최소포인트 MinPts를 사전에 설정해야 한다.
기타 군집 기법
퍼지 군집화
  • 한 데이터가 여러 군집에 속할 수 있다.
  • 군집 소속 정도를 확률·멤버십으로 표현한다.
  • 경계가 애매한 데이터에 유용하다.
EM 알고리즘
  • E-step: 현재 모수로 각 데이터의 군집 소속 확률 추정
  • M-step: 추정된 소속 확률로 모수를 다시 추정
  • E와 M을 반복해 가능도를 최대화한다.
SOM
  • 자기조직화지도(Self-Organizing Map)
  • 고차원 데이터를 저차원 격자에 매핑
  • 시각화와 군집 탐색에 활용
군집분석 평가
실루엣 계수
  • 군집 내 응집도와 군집 간 분리도를 동시에 평가
  • 범위는 -1~1, 1에 가까울수록 좋다.
  • 0에 가까우면 군집 경계가 애매하다.
WCSS
  • Within-Cluster Sum of Squares
  • 각 데이터와 소속 군집 중심 간 거리 제곱합
  • 작을수록 군집 내부가 조밀하다.
  • Elbow Method에서 K 선택에 사용한다.

🔥 3가지 지표 공식 필수 암기!
지지도 (Support)
P(A∩B)

A,B 동시 구매 확률

신뢰도 (Confidence)
P(A∩B) / P(A)

A 살 때 B도 살 확률

향상도 (Lift)
신뢰도 / P(B)

>1 양의연관 =1 독립 <1 음의연관

03-E+

연관분석 심화

연관분석 지표
  • 지지도 = P(A∩B): A와 B가 함께 나타날 확률
  • 신뢰도 = P(A∩B)/P(A): A가 있을 때 B도 있을 조건부 확률
  • 향상도 = 신뢰도/P(B): 독립 대비 얼마나 더 같이 나타나는지
  • 향상도 > 1이면 양의 연관관계, =1이면 독립, <1이면 음의 연관관계
Apriori 알고리즘
  • 빈발항목집합을 찾는 대표 알고리즘
  • Apriori 원리: 빈발항목집합의 모든 부분집합도 빈발해야 한다.
  • 지지도 기준 미달 후보를 제거해 탐색량을 줄인다.
  • 장바구니 분석에서 자주 출제된다.

하이퍼파라미터
  • 학습으로 자동 결정되는 값이 아니라 사용자가 사전에 설정하는 값
  • 예: 은닉층 수, 노드 수, 학습률, 배치 크기, 에폭 수, 드롭아웃 비율

출력층 활성화
  • 시그모이드: 이진분류, 출력 0~1
  • 소프트맥스: 다중분류, 각 클래스 확률 합=1
  • 선형 활성화: 회귀 문제

  • MSE: 회귀 모델에서 실제값과 예측값의 제곱오차 평균
  • Cross Entropy: 분류 모델에서 실제 클래스 확률과 예측 확률의 차이를 측정
  • 손실함수는 학습이 줄이려는 목표값이다.

03-G+

분류모델 평가 지표 심화

Fβ Score
Fβ = (1+β²) × (Precision×Recall) / (β²×Precision + Recall)
  • β=1이면 F1 Score
  • β>1이면 재현율을 더 중요하게 반영
  • β<1이면 정밀도를 더 중요하게 반영
ROC Curve와 AUC
  • ROC 곡선은 임계값 변화에 따른 FPR과 TPR의 관계를 나타낸다.
  • X축: FPR = FP/(FP+TN)
  • Y축: TPR = Recall = TP/(TP+FN)
  • AUC는 보통 0.5~1 범위로 해석하며, 1에 가까울수록 좋다.
  • AUC=0.5는 무작위 분류 수준이다.
암기: 암 진단처럼 FN이 위험하면 재현율·Fβ(β>1), 스팸 필터처럼 FP가 위험하면 정밀도·Fβ(β<1)를 더 본다.
03-G++

주성분분석(PCA)

PCA 핵심
  • 차원축소 기법이다.
  • 서로 상관된 여러 변수를 분산을 최대한 보존하는 새로운 축으로 변환한다.
  • 주성분들은 서로 직교하며, 제1주성분이 가장 큰 분산을 설명한다.
  • 변수 스케일이 다르면 표준화 후 수행하는 것이 일반적이다.
시험 포인트
  • 설명분산비로 몇 개의 주성분을 사용할지 결정
  • Scree Plot에서 급격한 감소가 완만해지는 지점 확인
  • 다중공선성 완화와 시각화에 활용
  • 해석력은 원래 변수보다 낮아질 수 있음

시계열 분석

시계열 데이터의 구성 요소
요소의미

정상성 조건

  • 모든 시점에서 분산이 일정

AR(p): 자기회귀 차수
I(d): 차분 횟수
MA(q): 이동평균 차수
ACF는 q, PACF는 p 판단에 활용
백색잡음(White Noise)
  • 평균 0, 분산 일정, 자기상관이 거의 없는 순수한 오차항
  • 정상성은 만족하지만 예측 가능한 패턴은 없다.
  • 시계열 모형을 잘 적합하면 잔차가 백색잡음처럼 보여야 한다.
암기: 비정상 시계열 → 차분/변환으로 정상화 → ACF·PACF로 ARIMA 차수 탐색 → 잔차가 백색잡음인지 확인
03-I

데이터 전처리

결측값 처리
  • 완전 삭제 — 결측 행/열 제거
  • 평균/중앙값 대치 — 수치형
  • 최빈값 대치 — 범주형
  • 다중대치법(MI) — 가장 정교
정규화 방법
Min-Max: (x-min)/(max-min) → 0~1
Z-score: (x-μ)/σ → 평균0,분산1
IQR: Q1-1.5×IQR~Q3+1.5×IQR
03-J

앙상블 학습

배깅 (Bagging)
  • 복원추출로 여러 모델 학습
  • 다수결/평균으로 합침
  • 대표: 랜덤포레스트
부스팅 (Boosting)
  • 이전 오류에 집중해서 순차 학습
  • 대표: XGBoost, AdaBoost
스태킹 (Stacking)
  • 여러 모델 결과를 메타모델에 입력
  • 가장 복잡하지만 성능 높음
